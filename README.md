# 🎨 Nexus Frontend

Interface utilisateur moderne pour la gestion de produits, clients et commandes. Connectée à l'API Auth et l'API Gestion.

## ✨ Fonctionnalités

- 🌓 **Mode Dark / Light** avec sauvegarde
- 🔐 **Authentification complète** :
  - Connexion par email/password
  - OAuth Google + GitHub
  - Bouton démo (test sans inscription)
- 📊 **Dashboard** avec graphiques temps réel
- 📦 **Pages détails** pour produits, clients, commandes
- 🛍️ **Galerie photos** pour les produits (3 vues)
- 🔍 **Recherche et filtres** dynamiques
- 🎨 **Design glassmorphism** ultra moderne
- 📱 **Responsive** (mobile-friendly)

## 🛠️ Stack technique

- **React 19** + **Vite**
- **Tailwind CSS 3**
- **React Router v6**
- **Axios** (HTTP requests)
- **Recharts** (graphiques)
- **React Hot Toast** (notifications)
- **Lucide React** (icônes)

## 📦 Installation

\`\`\`bash
# Cloner le projet
git clone https://github.com/dxtercodelab/nexus-frontend.git
cd nexus-frontend

# Installer les dépendances
npm install

# Lancer le serveur dev
npm run dev
\`\`\`

Ouvre **http://localhost:5173**

## 🌐 Configuration

Le frontend communique avec :
- **Auth API** : http://localhost:5000
- **Gestion API** : http://localhost:5001

## 🎨 Design

- **Mode Dark** : Glassmorphism + gradients
- **Mode Light** : Cartes blanches élégantes
- **Animations** : Transitions fluides
- **UX** : Tous les éléments cliquables

## 📱 Pages
